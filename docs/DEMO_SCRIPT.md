# 3-5 Minute Demo Script

## 0:00 - 0:30 Intro

- Introduce problem: manual screening is slow and inconsistent
- Introduce solution: AI TalentScout for JD parsing, matching, outreach, and ranking

## 0:30 - 1:20 Job Description Parsing

- Paste a realistic JD
- Click analyze
- Show extracted role, skills, and experience

## 1:20 - 2:10 Candidate Upload + Matching

- Upload `samples/sample_candidates.csv`
- Run matching
- Show matched vs missing skills and match score

## 2:10 - 3:10 Outreach + Response Update

- Open outreach panel
- Show candidate email extraction from CSV
- Click "Send Job Email" (mailto flow)
- Mark different response statuses (Interested / Maybe / Not Interested)
- Explain how interest score updates

## 3:10 - 4:20 Final Shortlist + Explainability

- Generate final shortlist
- Explain weighted scoring:
  - skill, experience, availability, interest
- Show recommendations (Proceed / Keep warm / Reject)
- Export results CSV

## 4:20 - 5:00 Close

- Highlight practical value for recruiters
- Mention deployment URL + GitHub repo + docs included
